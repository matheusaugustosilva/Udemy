# 🌐 Desenvolvimento Web Moderno com JavaScript

Repositório dedicado ao estudo e prática de desenvolvimento web moderno, com foco na construção de aplicações completas utilizando tecnologias atuais do mercado.

---

## 🚀 Sobre

Este repositório reúne exercícios, anotações e projetos desenvolvidos ao longo do curso **Desenvolvimento Web Moderno com JavaScript**, abordando o desenvolvimento **frontend e backend** e a criação de aplicações reais.

---

## 🧰 Tecnologias Utilizadas

* HTML
* CSS
* JavaScript
* Node.js
* React
* Vue.js
* Express
* MySQL
* MongoDB
* Git & GitHub

---

## 🛠️ Projetos

* Interfaces e layouts responsivos
* Manipulação do DOM
* APIs e aplicações com Node.js
* CRUD com banco de dados
* Aplicações com frameworks modernos
* Projeto fullstack integrando frontend e backend

---

## 🎯 Objetivo

Desenvolver habilidades práticas em desenvolvimento web moderno e construir aplicações completas alinhadas às demandas do mercado.
